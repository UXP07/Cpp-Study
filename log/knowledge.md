# 知识点清单

依据 `log/学习计划细化_AI推理端与量化低延迟交易系统.md` 整理，共 **69** 个知识点。

- **排序**：波次之间由浅入深；**同一波次内可并行学习**（波次 3b 数学建议全程并行穿插）
- **状态**：`未学习` → `学习中`（出题后自动改）→ `已学习（日期）`（用户确认后才改）
- **出题**：对 Claude 说"按 N 号出 M 道题"；验收后说"把 N 号标为已学习"
- **环境标注**：`[Linux]` 动手需 WSL2/虚拟机；`[GPU]` 需 NVIDIA GPU；`[Python]` 需 Python 环境；未标注 = 本机 MinGW 可动手。环境不可用时出概念/代码阅读/设计题替代
- **#8 为了解级**（g++ 8.1 对 C++20 支持有限，动手实验需升级 GCC）
