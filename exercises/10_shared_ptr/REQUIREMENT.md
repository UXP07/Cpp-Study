// 练习 10 —— 智能指针：所有权建模与引用计数（知识点 #3 智能指针）

## 背景

你已经手写过一个"只移动句柄类"（06-09 的 Blob/LogFile）——那就是 `unique_ptr` 的本体。
本次进入新大陆：**共享所有权**。多个持有者共同拥有一个对象，最后一个离开的人关灯。

两个战场：

- **Part A**：双向链表节点。两个节点互指，释放后必须双双死亡——这个场景会逼出
  智能指针最著名的陷阱（循环引用）和它的解药。
- **Part B**：手写简化版引用计数智能指针 `Shared<T>`——把 `shared_ptr` 的心脏
  （堆上的迷你控制块）亲手造一遍。

**零输出要求**：所有类不打印任何东西，验收全部走判题端计数器驱动，main 留空。

## 需求

### 公共载荷

**Q1. class Widget**
`Widget(int)` 构造、不可拷贝；`value()` 查询；静态 `live()` 活计数
（构造 +1、析构 -1）。它是本题所有权关系的"被拥有者"。

### Part A：class Node —— 循环引用拆弹

**Q2.** 默认构造、静态 `live()`；提供 `set_next` / `set_prev` 建立双向链接
（**两个方向的参数类型由你选择**——选择的正确性由验收判定），并提供
`next()` / `prev()` 查询，要求从任一节点能拿回对方的 `std::shared_ptr<Node>`。

### Part B：template Shared\<T\> —— 手写引用计数

**Q3. 生命周期全套**
- 默认构造为空；`explicit` 接收裸指针（接管所有权，计数置 1）
- **拷贝构造/拷贝赋值**：共享同一份资源，计数 +1；拷贝赋值先释放自己旧份额、
  自赋值安全
- **移动构造/移动赋值**（`noexcept`）：过户，**计数不变**，源置空
- 析构：计数 -1，**最后一份释放时资源与控制块同亡**

**Q4. 计数放在哪（本题的题眼）**
计数必须被所有副本共享——想清楚它为什么不能是对象成员，应该放在哪里。
提供 `use_count()`（空对象返回 0）与 `get()`。

**Q5. 指针语义**
`operator*` 与 `operator->`，让 `Shared<T>` 用起来像指针。

## 验收标准（判题端驱动逐条核对）

- std 智能指针基线：`make_shared` + 拷贝共享，`use_count` 与 `Widget::live` 关系正确
  （拷贝不复制资源）
- **循环引用**：两个 Node 双向链接后整体释放，`Node::live()` 必须归零
  （若两个方向都选了"持有"型指针，live 卡住不降——驱动直接判 FAIL）
- `Shared<Widget>` 计数锚点：接管=1；拷贝后 2；作用域副本消失回到 2；
  **移动后计数不变**（2）；移动源 use_count()==0 且 get()==nullptr；
  空对象全程安全；空对象被移动赋值后"复活"
- `Widget::live()` 全程与"是否还有持有者"一一对应；程序结束归零
- 自赋值后计数不变；`operator*`/`operator->` 取回 value 正确
- 编译期：可拷贝、可移动、移动 noexcept、可默认构造

## 简答题（答案写在 main.cpp 顶部注释块）

SR1. 选用判据：什么时候用 unique_ptr / shared_ptr / weak_ptr / 裸指针+引用？
     给一张"所有权判据表"（含：函数参数只想用不想拥有时选什么）。
SR2. 计数为什么不能是 Shared<T> 的普通成员？它必须满足"被所有副本共享"，
     这和练习 03 浅拷贝观察到的现象是同一个原理吗？拷贝和移动对计数各做什么，
     为什么？`make_shared` 比先 new 再构造 shared_ptr 好在哪？
SR3. 循环引用为什么让 shared_ptr 的计数永远到不了 0？weak_ptr 是怎么拆掉环的？
     为什么用之前必须 lock()，lock 返回什么？
SR4. 拷贝赋值里"先释放自己旧份额、再共享对方"的顺序能不能反？
     自赋值走不走这条路径，为什么安全？

## 约束

- Node 的 `set_next/set_prev` 参数类型自选（这正是考点），但两个方向都要能取回
  `shared_ptr<Node>`；可使用 `<memory>` 的标准智能指针
- Shared<T> 计数机制必须手写（不许多余包装 std::shared_ptr），但**不要求**线程安全
  （单线程即可，原子计数是以后波次 2 的事）
- 三个类/模板**零输出**；C++17；注释中文
- 构建：`cmake --build --preset default --target 10_shared_ptr`
- 模板必须被实例化验证（09 的教训）：判题驱动会真用 `Shared<Widget>`
